# Scribble V2 Upgrade Summary

## Key Features Added

- Word choice phase with 3 options and a timeout
- Timed hint reveals during drawing
- Room settings (max players, round time, total rounds)
- Spectator mode for full/in-progress rooms
- Undo + stroke history sync for late joiners
- Ping/latency display and improved reconnect handling
- Polished lobby/room layouts and updated styling

## How To Run

```bash
./gradlew :scribble-server:run
./gradlew :scribble-client:run
```

Default host: `localhost`, port: `5555`
